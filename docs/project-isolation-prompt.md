# 给同服务器其他项目的提示词

```text
请为本项目整理开发、测试、发布和回滚流程，避免开发中的修改直接影响正在运行的正式服务。

请根据本项目特点处理，不要机械照搬其他项目的目录、端口、技术栈、命令或部署方案。先检查项目说明、Git 状态、现有服务、反向代理、配置、数据与依赖，保留未提交改动和已有功能。

把项目专用文件统一归入本项目工作区；系统共享工具、反向代理入口和服务注册按实际需要保留。开发环境与正式环境分开配置、密钥、数据及端口。正式服务独立托管，关闭编辑器后仍能运行；正式版本固定到确定的提交或构建产物，修改源码不直接上线。

提供适合该项目的开发预览、测试、发布、健康检查和回滚方法。发布前验证，切换失败时尽可能恢复旧服务；涉及数据库或数据格式变更时单独处理兼容与备份，不能把回退代码等同于回退数据。根据服务器资源选择足够简单的实现。

采用适合本项目规模的分支、PR 和 CI 流程。不要打印或提交真实密钥、用户数据、凭证和私人配置，不要拿正式数据做测试，也不要改动本服务器其他项目。

先完成检查与可验证的方案，再实施已经明确且可恢复的调整。发现可能丢失数据、无法回滚、影响其他服务或缺少关键授权的步骤时，说明具体影响再确认。完成后实际验证，告诉我改了什么、开发入口在哪、如何发布和回滚、还有什么没有验证，并把约定写入本项目文档。
```
