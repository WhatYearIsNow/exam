## 为什么代码 MIT 与题库要分别处理

著作权法区分具有独创性的文字、图形等表达与通用公式。不能仅因题目属于数学或物理，就认定其整段题面、附图或整套编排均可任意再分发。整理、注释、汇编产生的贡献，也不自动替代原材料的权利。[依据：著作权法第三、五、十三、十五条](https://www.ncac.gov.cn/xxfb/flfg/flfg_532/202103/t20210309_50530.html)。

因此，你自写的解析和勘误应当保留贡献记录；修正答案不等于取得原题、原图的再分发许可。MIT 声明用于原创代码，第三方材料继续按其真实来源处理。

## 学习用途、署名与公开 GitHub

个人学习、课堂教学等存在法定使用限制和条件，不能直接推导为向所有 GitHub 访问者发布整套题库的通用许可。法律对课堂与科研使用规定了范围限制；网络传播条例也对教学科研中的对象和数量作了限制。[著作权法第二十四条](https://www.ncac.gov.cn/xxfb/flfg/flfg_532/202103/t20210309_50530.html)、[信息网络传播权保护条例第二、六条](https://xzfg.moj.gov.cn/law/download?LawID=1253&type=pdf)。

“免费”“注明来源”“仅供学习”可以说明用途或提供线索，但单独写这些文字不能确认具体材料的授权。判断某份材料能否公开，需要看其原始来源、作者或权利人、公开许可或授权，以及实际使用方式。

## 如何补齐来源记录

对每份原始材料记录名称、版本、取得渠道、原始链接、作者或权利人信息，以及可核实的许可或授权范围。`exam` 的使用范围是网页展示和题库数据提供，应对应题面、附图、解析和确认修正；`zhenti-pipeline-v2` 的 PDF 制作与分发范围在该项目中另行核对。个人信息和不适合公开的凭证仍保留在本地。

对自己编写的题和解析，标注原创作者与许可；对他人材料保留原始来源并逐份确认。来源不明的材料可以继续调查、替换为自编内容，或采用公开程序、由使用者自行导入题库的方式。当前是否调整公开内容，应根据来源核实结果决定。

当前题库已随仓库公开。以后仅删除最新目录中的题库，旧提交、标签和 Release 源码包仍可能保留内容；如需撤回某份材料，应单独核对这些位置，不把一次普通删除提交当作彻底撤回。
